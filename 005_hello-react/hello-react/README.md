# Hello React

This is a simple React application that demonstrates basic form handling and state management.

## Features

- **Greeting Form:** Enter your name and receive a personalized greeting.
- **Validation:** Prompts the user to enter a name if the input is empty.
- **Responsive UI:** Clean and modern styling using CSS.

## Getting Started

1. **Install dependencies:**
   ```
   npm install
   ```

2. **Run the app:**
   ```
   npm start
   ```

3. **Open in your browser:**
   Visit [http://localhost:3000](http://localhost:3000)

## Usage

- Enter your name in the input field.
- Click "Create Message" to see a greeting.
- If no name is entered, a prompt will ask you to enter a name.

## Project Structure

- `src/components/Hello.jsx` - Main component with the greeting form.
- `src/components/Hello.css` - Styling for the Hello component.
- `src/App.jsx` - Main application component.
