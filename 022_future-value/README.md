# Future Value Calculator

This is a simple React application that helps you estimate the future value of your savings with monthly contributions and compound interest.

## Features

- Enter a monthly contribution amount, number of years, and annual interest rate.
- Calculates the future value using monthly compounding.
- Clean, responsive layout with sidebar instructions.

## Usage

1. Enter your monthly savings amount, the number of years you plan to save, and the expected annual interest rate.
2. Click **Calculate** to see the estimated future value of your savings.

## Development

This app uses [Vite](https://vitejs.dev/) for fast development and [React](https://react.dev/) for the UI.

### Scripts

- `npm run dev` – Start the development server
- `npm run build` – Build for production
- `npm run preview` – Preview the production build
- `npm run lint` – Run ESLint
