# Hello Plain React Example

This is a simple web application that displays a personalized greeting message based on user input.

## Features

- Enter a name and receive a greeting message.
- Simple, accessible form.
- Styled with CSS.

## Usage

1. Open `hello-plain/index.html` in your browser.
2. Enter your name in the input field.
3. Click "Create Message" to see your greeting.
